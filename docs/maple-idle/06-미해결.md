## 🔴 최우선 — 공식 전체 검증

### 블래스트 1타 실제 데미지
아래 추정치와 게임에서 실제로 뜨는 숫자를 대조해야 한다.

```
최종 챕터(방어 7,100) 일반 몬스터 · 버프 평균 가동률 반영

계수 460.5% 그대로        → 약 107조  (범위 77조~138조)
마스터리 피해량 ×1.21 반영 → 약 130조
노블디맨드 디버프 ON       → 위 값 ×1.228 / OFF면 ÷1.109
```

**이 숫자 하나가 세 가지를 동시에 판별한다:**
1. 크리티컬 데미지 252.5% = **×3.525배**가 맞는지 *(전투력 식 `(크리뎀−300)`에서 역산한 추정)*
2. 최소/최대 데미지 배율(184.7%~333.2%)이 **그대로 곱해지는 배율**인지
3. **마스터리 피해량이 합연산(+21%)인지 곱연산(×1.11×1.10)인지**
   → 사전에 "스킬 구현에 따라 다르게 적용"이라고만 돼 있어 문서로는 알 수 없음
4. 사냥에 별도 콘텐츠 보정이 있는지 / 받는 피해 증가가 그 위치에서 곱해지는지

## 🟠 랭킹표를 확정시키는 값들

| # | 필요한 값 | 없으면 무슨 문제 |
|---|---|---|
| 1 | **현재 주스탯 %** | 랭킹 2위(주스탯 +0.911%)가 **과대평가**일 수 있음 |
| 2 | **평타 : 스킬 딜 비중** | 기본공격뎀 / 스킬뎀 / 쿨감 순위가 안 정해짐 |
| 3 | **쿨감 % / 쿨감(초) 현재값** | 쿨감 옵션 정확도 |
| 4 | **버프 지속시간 증가 현재값** | +20% 넘었으면 **상위권 → 무가치**로 급변 |
| 5 | **캐릭터 레벨** | "1레벨당 주스탯" 옵션 계산 |

### 1번이 왜 중요한가
사전 1.1 "합 + 배율" — 주스탯 % 옵션은 **고정 주스탯 합계**에 곱해진다.
화면의 STR 107,109에 곱해지는 게 아니다. 이미 주스탯%를 100% 쌓았다면 실제 증가는 절반 수준.

**측정법**: 주스탯% 붙은 장비 하나 뺐다 꼈다 하며 STR 변화 관측.
예) +10% 옵션 제거 시 107,109 → 102,000이면 고정 합계 = 51,090

**공격력 +1%(+1.000%)도 같은 함정을 갖는다.**

## 🔵 2026-08-08 갱신 — skills.xlsx 반영분

### 해결된 것
- **블래스트 기본 타수 = 5** (전직업 기본공격 공통). 마스터리 "타격 횟수 +1"은 **+20%**
- **기본공격은 쿨타임이 없다** — 공격속도에 맞춰 반복 시전되는 액티브
- **계수 단위 = 배율** (0.4~48). 블래스트 1레벨 2.9 ↔ 기준 캐릭 4.605

### 수정된 수치
| 항목 | 어제 | 지금 | 이유 |
|---|---|---|---|
| 블래스트 실효 계수 | ×1.21 → 557% | **×1.96 → 903%** | 4차 기본공격 마스터리 피해량 +75% 공통 확인 |
| 1타 추정 | 130조 | **약 211조** | 위와 동일 |
| 보스 몬스터 데미지 +1% | +0.909% | **+0.769%** | 보스뎀 공통 20% + 팔라딘 10% = 30% *(합산 여부 미확인)* |
| **공격 속도 +1%p** | +0.19% | **약 +0.13%** | 공속은 **기본공격에만** 직결. 액티브는 쿨 지배 → `평타 비중 × 공속 증가율` |

### 새로 생긴 미지수
- [ ] **기본공격의 기본 시전 주기** (공속 0% 기준 초당 몇 회)
      → 이게 있어야 **딜 비중(평타:스킬)이 계산으로 나온다.** 지금은 감 입력
      → 측정법: 게임에서 10초간 블래스트 타격 횟수 세기
      → 1레벨 계수·쿨로 거칠게 돌리면 **평타 : 스킬 ≈ 68 : 32** (블래스트 초당 1회 가정)

### 어제 대화 ↔ 시트 불일치 (확인 필요)
- [ ] **민첩한 몸놀림** — 어제: 액티브 버프 쿨60/지속15 / 시트: **없음**
- [ ] **디바인 차지** — 어제: 마스터리 6개가 여기 몰림 / 시트: **없음**
      (시트엔 `홀리 차지`(2차 패시브), `어드밴스드 홀리 차지`(4차 패시브)가 있음 → 오독 가능성)
- [ ] **파라쇼크 가드** — 어제: 버프 중 공격력 +10%p / 시트: **패시브**
      → 패시브면 상시 발동이므로 **스탯창에 이미 포함 = 계산에서 제외**해야 함
- 반대로 어제 목록에 없던 **디바인 블레싱**(쿨30/지속22), **매직 크래쉬**(쿨28/계수48)가 시트엔 있음
  → 매직 크래쉬는 계수 48로 최대값. 팔라딘 스킬 딜의 상당 부분일 것
