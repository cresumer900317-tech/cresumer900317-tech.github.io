# 직업별 스킬·마스터리 데이터

DB로 내장할 부분.

## 수집 기준 (확정, 2026-08-08)

- **스킬 계수는 전 스킬 1레벨 기준으로 수집한다.** 직업 간 동일 조건 비교·밸런스 랭킹의 기준선.
  사용자 본인 딜 계산에는 본인 계수를 입력받는다 (1레벨 DB 값으로 대체 금지).
- **타수와 대상 수는 구분해서 적는다.** 타수 = 1회 시전에 몇 번 때리는가, 대상 수 = 몇 명을 때리는가.
  대상 수는 스테이지(다수 몹) 시뮬에 필요, 보스 단일 대상 계산엔 불필요.
- 수집 원본: 집 PC `OneDrive\문서\메이플키우기 스킬데이터.xlsx` (시트: 전사/법사/도적/신궁/해적/시그너스)

## 직업 14종 ↔ 주/부 스탯 (확정)

| 계열 | 직업 | 주스탯 | 부스탯 |
|---|---|---|---|
| 전사·해적 | 히어로, 팔라딘, 다크나이트, 바이퍼, 캡틴 | STR | DEX |
| 궁수 | 보우마스터, 신궁, 윈드브레이커 | DEX | STR |
| 마법사 | 불독, 썬콜, 비숍 | INT | LUK |
| 도적 | 나이트로드, 섀도어, 나이트워커 | LUK | DEX |

- **부스탯 4 = 주스탯 1** (공격력 반영 100%:25%, 스탯비례뎀 100당1%:400당1% — 양쪽 다 4:1)
- 유효 스탯 = 주스탯 + 부스탯 ÷ 4
- ⚠️ mgf.gg 제보 폼에는 12직업만 있음(윈드브레이커·나이트워커 누락). 14가 맞음

[스킬 피해량]  ※ 스킬 계수에 마스터리가 반영 안 되므로 필요
생츄어리 피해량 +50%
블래스트 피해량 +11%, +10%
디바인 차지 피해량 +15%, +14%, +13%

[기타]
디바인 차지 적 타격 횟수 +1

## 수집 템플릿 (나머지 13직업)

길드에 그대로 던질 것. 직업당 5분.

```
■ 직업: ○○○

[스킬]
이름          | 종류(기본공격/공격/버프/디버프) | 기본쿨 | 지속 | 효과
...

[마스터리 — 아래 4종류만]
① 스킬 쿨감 %
② 버프 효과 추가 (버프 중 ○○ 증가)
③ 스킬 피해량 +%
④ 타격 횟수 / 스킬별 보스뎀

❌ 전역 스탯 마스터리(스킬데미지 +15% 등)는 적지 말 것 — 스탯창에 이미 포함
```

**"버프·디버프의 효과와 지속시간"이 핵심**이다. 쿨감·버프지속 옵션의 가치를 결정한다.
