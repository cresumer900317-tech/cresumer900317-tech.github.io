# 직업별 스킬·마스터리 데이터

DB로 내장할 부분.

## 수집 기준 (확정, 2026-08-08)

- **스킬 계수는 전 스킬 1레벨 기준으로 수집한다.** 직업 간 동일 조건 비교·밸런스 랭킹의 기준선.
  사용자 본인 딜 계산에는 본인 계수를 입력받는다 (1레벨 DB 값으로 대체 금지).
- **타수와 대상 수는 구분해서 적는다.** 타수 = 1회 시전에 몇 번 때리는가, 대상 수 = 몇 명을 때리는가.
  대상 수는 스테이지(다수 몹) 시뮬에 필요, 보스 단일 대상 계산엔 불필요.
## 데이터 파일 (2026-08-08 레포로 이관)

```
skills.xlsx           원본. 사람이 Excel로 편집. 시트 = 스킬데이터 / 기준·현황
build-skills-json.py  변환기
skills.json           계산기가 읽는 것 (생성물, 직접 수정 금지)
```

편집 후 `python3 docs/maple-idle/build-skills-json.py` 실행 → 커밋.

⚠️ **xlsx는 바이너리라 git이 병합을 못 한다.** 편집은 한 번에 한 기기에서만 하고 끝나면 바로 push.
⚠️ OneDrive 사본(`문서\메이플키우기 스킬데이터.xlsx`)은 **아카이브**. 원본은 이제 레포다.
   맥에는 OneDrive 앱이 없어 접근 불가 — 집 PC에서도 `git pull` 후 레포 파일을 열 것.

## 직업 14종 ↔ 주/부 스탯 (확정)

| 계열 | 직업 | 주스탯 | 부스탯 |
|---|---|---|---|
| 전사·해적 | 히어로, 팔라딘, 다크나이트, 바이퍼, 캡틴 | STR | DEX |
| 궁수 | 보우마스터, 신궁, 윈드브레이커 | DEX | STR |
| 마법사 | 불독, 썬콜, 비숍 | INT | LUK |
| 도적 | 나이트로드, 섀도어, 나이트워커 | LUK | DEX |

- **부스탯 4 = 주스탯 1** (공격력 반영 100%:25%, 스탯비례뎀 100당1%:400당1% — 양쪽 다 4:1)
- 유효 스탯 = 주스탯 + 부스탯 ÷ 4
- ⚠️ mgf.gg 제보 폼에는 12직업만 있음(윈드브레이커·나이트워커 누락). 14가 맞음

## 전직업 공통 마스터리 7종 (확정, 2026-08-08)

아래 7개는 **전직업 공통**이고 **스탯창에 이미 적용된 것으로 간주**한다.
계산기에 넣으면 이중 계산 — 수집은 기록용으로만, DB/계산에서 제외 (CLAUDE.md 원칙 4의 구체 목록).

```
명중 5 증가
주 스탯 30 증가
크리티컬 확률 5% 증가
스킬 데미지 15% 증가
```

## 4차 기본공격 마스터리 공통 (확정, 2026-08-08)

전 직업의 4차 기본공격 스킬 마스터리는 동일하다 (스킬명만 다름). 이건 스탯창 미포함 — **계산에 사용**:

```
○○(기본공격 스킬명) 피해량 75% 증가
보스 몬스터 데미지 20% 추가 적용
적 타격 횟수 1 증가
```

직업별 4차 기본공격: 팔라딘 블래스트 / 히어로 레이징 블로우 / 다크나이트 다크 임페일 /
비숍 빅뱅 / 썬콜 체인 라이트닝 / 불독 플레임 스윕 / 섀도어 크루얼 스탭 / 나이트로드 쇼다운 챌린지 /
신궁 인핸스 피어싱 / 보우마스터 언카운터블 애로우 / 바이퍼 훅 봄버 / 캡틴 퍼실레이드 / 윈드브레이커 페어리 턴
/ 나이트워커 퀸터블 스로우

### 기본공격 스펙도 전직업 동일 (확정, 2026-08-08)

```
차수 4차 · 계수 2.9 (1레벨) · 타수 5 · 대상수 6 · 쿨타임 없음
```

- **쿨타임이 없다.** 평타처럼 쓰지만 액티브 스킬이고, **공격속도에 맞춰 반복 시전**된다
  → 계산기는 기본공격을 "쿨 지배"가 아니라 **"공속 지배"**로 모델링해야 한다
- 마스터리 "적 타격 횟수 1 증가"는 **5 → 6이므로 +20%** (2배 아님)
- 14직업이 스펙까지 같으므로 **직업 간 밸런스 비교에서 기본공격은 변수가 아니다**

**공격속도 옵션의 가치가 여기서 결정된다.** 공속은 기본공격 빈도에 직결되지만
액티브 스킬은 쿨이 지배하므로 영향이 작다 → **공속 가치 ≈ 평타 비중 × 공속 증가율**

## 수집 템플릿 (나머지 13직업)

길드에 그대로 던질 것. 직업당 5분.

```
■ 직업: ○○○

[스킬]
이름          | 종류(기본공격/공격/버프/디버프) | 기본쿨 | 지속 | 효과
...

[마스터리 — 아래 4종류만]
① 스킬 쿨감 %
② 버프 효과 추가 (버프 중 ○○ 증가)
③ 스킬 피해량 +%
④ 타격 횟수 / 스킬별 보스뎀

❌ 전역 스탯 마스터리(스킬데미지 +15% 등)는 적지 말 것 — 스탯창에 이미 포함
```

**"버프·디버프의 효과와 지속시간"이 핵심**이다. 쿨감·버프지속 옵션의 가치를 결정한다.
