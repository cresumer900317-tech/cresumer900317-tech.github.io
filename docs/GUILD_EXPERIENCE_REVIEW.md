## 데이터 출처와 범위

- MGF 공개 길드 페이지: `.guild-update-row`, `.member-row[data-bp][data-gb]`. 원본 기준일과 조회 시각을 별도로 노출한다.
- 원본: https://mgf.gg/contents/guild_info.php?g_name=%EC%B9%9C%EA%B5%AC%EB%93%A4
- 원본 숫자 속성을 이용해 토벌 점수를 수집한다. 확인하지 못한 값은 null이며 0점과 다르다.
- 원본 페이지 조회는 등록된 5개 길드만 허용. 1시간 캐시, 길드별 동시 요청 잠금, 실패 시 5분 재요청 제한, 10초 타임아웃. 차단 응답을 우회하지 않는다.
- 기존 정기 길드 크롤이 성공하면 동일 HTML로 원본 캐시를 채우며 추가 요청을 줄인다.
- 길드원 수집에서 확보한 토벌 점수를 저장한다. 별도 보스 랭킹 수집 실패 시 기존 점수를 지우지 않는다.
- 스테이지·길드 콘텐츠·공식 공지는 검증된 원본 링크로 연결하며, 확인되지 않은 게임 일정/접속 상태/참여 여부를 생성하지 않는다.
- 전체 서버 7,000명 수집은 기존 크롤러의 차단·부분 수집 보호 정책을 유지한다. 새 길드 원본 API는 전체 서버 순위를 최신화한다고 주장하지 않는다.

## 검증

- Python 11개 테스트: 관측 병합·기간·동일 구성원·원본 점수·차단/잘못된 길드 페이지 거부.
- JavaScript 6개 계약 테스트: 날짜 필터·점수·타임존·최신 전투력과 순위 시점 분리.
- 로컬 DOM 환경에서 공개 API 응답을 재현해 14개 화면 렌더링 및 관심/내 캐릭터 저장 검사. 이는 실제 인증 검증이나 모바일 브라우저 검증을 대체하지 않는다.
- `tools/responsive-preview.html`은 360/390/768/1280px에서 실제 페이지를 iframe으로 표시하는 noindex 검증 도구다. 운영 메뉴에는 노출하지 않는다.
- 결혼식 갤러리, 개인 업무 페이지, 관리자 운영 데이터는 이번 길드 사용자 화면 개편 범위 밖이다.
